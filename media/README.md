# Media

Public-facing screenshots and thumbnails for Blender Workflow Lab.

- `screenshots/calipers/` — Calipers interface and workflow screenshots.
- `screenshots/seam-path-tool/` — Seam Path Tool interface and workflow screenshots.
- `screenshots/uv-island-overlay/` — UV Island Overlay interface and workflow screenshots.
- `thumbnails/` — Cover images and linked-video thumbnails used in project documentation.

Prefer optimized WebP images, or PNG when UI text needs lossless clarity. Keep
original recordings and editing project files outside the Git repository.
